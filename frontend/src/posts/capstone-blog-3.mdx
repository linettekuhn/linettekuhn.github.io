This week, I spent some time diving deeper into the technologies I’ll be using moving forward. Like last week, I continued to research, but this time I decided to actually get my hands dirty. One of my lab instructors recommended checking out an official Android training course, so I chose [Android Basics with Compose.](https://developer.android.com/courses/android-basics-compose/course)

The course walks through building Android apps from scratch using Jetpack Compose and the Kotlin programming language.

So far, I have completed the first unit of this course, where I learned how to create a simple Android app with a user interface that displays images and text. I also got more comfortable with Kotlin’s syntax, which feels a lot like TypeScript, so it clicked pretty quickly for me. After that I set up Android Studio and created my very first project. This helped me get familiar with the IDE, Android’s project structure, and how to use Composable functions to display UI elements like text and images, arranged in layouts like columns, rows, and boxes. The best part was finally emulating the project on a virtual device and seeing my first Android app come to life!

By the end of this week I also got access to the Echelon Reflect Mirror repo on GitHub, the Jira board with all the tickets, and the Zeplin project with all app designs. Setting up the right Android Studio and Gradle versions took some troubleshooting, but I finally got the project running on my machine, so that’s definitely progress!

This means my work with Echelon has officially started as I claimed my first ticket and created a branch to develop on. Right now, I am working on the EchelonAI Class Card UI. The project setup is still giving me a hard time, with some strange errors, but I’m sure we’ll sort it out in the coming week.

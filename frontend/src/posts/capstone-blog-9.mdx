This week, I focused on improving my own projects, which meant dusting off my Project and Portfolio 4 project, EasyCook. When I initially worked on it, I mainly focused on getting the functionality right, so I wasn’t fully satisfied with the final UI. It was also the first website I developed, so I wanted to incorporate some of the skills I’ve gained along the way. I completely redesigned the website while still keeping the original idea of having a color theme for each page. I chose a less intense background color, using them as accent colors instead, and selected a more readable font. Here, you can appreciate the before and after of this new style:

![Before and after redesign](/gifs/easy_cook_redesign_static.gif)
_Before and after redesign_

Next, I wanted to explore using an animation library I found called Motion. With this, I can add animations within the JSX, which really simplifies the process of creating animations. I started creating some flip card animations on the main page, which provide a brief description of each subpage and encourage the user to click them.

I saw that I could animate SVGs and wanted to try this out as well. For the profile icon, once the modal is open, it turns into a close icon, and I wanted to transition between the two smoothly. This involved using a tool called Flubber, which interpolates between the two icons, combined with Motion to animate the transition. Lastly, I worked on redesigning the buttons and input boxes so they match the new theme. This is the result of how the site looks so far:

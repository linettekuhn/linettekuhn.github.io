I just wrapped up the second week of my capstone project at Full Sail University, and I’m excited to share that I’ll be working with Echelon alongside my classmates! This means, we’ll be helping develop features for their [Reflect smart mirror](https://echelonfit.com/products/echelon-reflect-touch-50-fitness-mirror-for-bundles) UI.

My background is mostly in web development, so I’m excited to see what comes from developing apps instead. Since we’re dealing with Android development, we’ll be using Kotlin and Jetpack Compose (two technologies I’ve never explored before).

In my research, I noticed these two share a lot of similarities with JavaScript and React, and the more I compared them, the more it started to make sense. Kotlin closely resembles TypeScript in that it has strong explicit types, null safety, and modern syntax while still being compatible with older code. So, Kotlin can be thought of as a stricter, Android-focused version of TypeScript, providing the core functionality for the app.

On the UI side, we’ll be using Jetpack Compose, which is a declarative UI framework similar to React. Both frameworks use functions to build the UI: React has components, while Compose has composables. They also both use state to track changes in the UI and re-render specific elements when needed. Instead of returning HTML tags like in React, Compose uses functions for everything; even elements on screen like buttons and text are functions. Another key difference is styling: React uses CSS, while Compose uses modifiers to handle layout and styles.

There’s still a long way to go, but I’m excited to learn Android development and eventually build multiplatform apps in the future!

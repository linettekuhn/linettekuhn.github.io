Hello! My name is Linette Kühn, and this blog post is the first of many documenting my journey through my final capstone project at Full Sail University.

I've come a long way exploring the many different branches of Computer Science during my time at Full Sail. After a lot of soul searching, I found myself really enjoying web development, especially the frontend aspect of it.

My main goal for this capstone project is to keep exploring and improving in this craft. And it all begins with this blog, fully created by yours truly, simply using React and [MDX](https://mdxjs.com).

I've already built a few sites with React, and I hope to make this site my portfolio in the future. But for now, it serves as my personal blog.

MDX is a new technology for me, but in short, it allows the use of JSX components inside Markdown files, adding an extra layer of interactivity to my blog posts. For this initial post, I don’t really need it, but I included it to make this site a little more interesting and to save myself a future headache if I want to add React components later.

Looking ahead, in the coming months, I hope to collaborate with Echelon and work with their app development team to create better UI for their smart mirror. If that doesn’t work out, I’m also excited to team up with my classmates to build one of our pitched projects.

Whatever happens, I’m satisfied with my journey so far and optimistic about what’s ahead :)

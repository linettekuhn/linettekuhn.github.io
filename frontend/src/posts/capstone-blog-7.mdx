During this week, I shifted my focus to personal projects while I wait for my previous code to be merged so that I can continue working on tasks for Echelon, and if you’ve seen my website before the publication of this post, you probably already noticed what I’m talking about. After some feedback from my peers and professors, I decided to work on having a more cohesive design on my portfolio website that resonates more with my personality and style.

I started out with Figma, putting into effect some ideas I’ve had for the design. I wanted my website to have two looks: a light theme and a dark theme, which can be switched by a lamp button in the navigation bar. For the light theme, I wanted it to have a more professional and calm look, matching tones of nature for the primary accents. To contrast, the dark theme explores more of my creative side, with funkier fonts and bright and glowy colors as primary accents. So, I ended up creating these style guides:

![Style guides for dark and light themes](/images/portfolio-website-design-cards.png)
_Style guide cards for the light and dark theme_

With the design out of the way, it was time to actually start coding. The first thing I did was add the winking ü (u umlaut) character animation in my last name. I did this by creating an SVG component on Figma and targeting each element of this icon through CSS to transform through the animation. This opened up the world of CSS animations, which is something I hadn’t explored before, but I’m really excited to keep implementing these animated icons on my page.

![Winking U Umlaut](/gifs/winking_u.gif)
_Winking smiley face animation_

After this, I worked on actually implementing my new dark and light themes. Thankfully, I had a good template with what I already had, so all I had to do was tweak the spacing, fonts, and colors. I also redesigned the navigation bar to have a glass-like background color and to include a hamburger menu to link to other pages within the site and, of course, the lamp button that picks the theme.

![Light theme mobile view](/images/portfolio-after-light.png)
_Light theme mobile view_

![Dark theme mobile view](/images/portfolio-after-dark.png)
_Dark theme mobile view_

Lastly, I added some hover and click animations to most buttons and created a new contact page. Within this page, I added a contact form that automatically sends emails to my personal inbox using [Web3Forms](https://web3forms.com). I also included some social links on this page, like for my LinkedIn and GitHub profiles.
The site is definitely not done, but it's a world of a difference from where we started, and I'm satisfied with the outcome so far. I want to keep adding more features to make this website as much of a representation of me as possible. Feel free to explore this site to see the result of my hard work!
